Generare raport

Pagina afișează parametrii raportului ales din Rapoarte. Completați parametrii, alegeți formatul de export și apăsați Generează raport.

Fiecare raport are propriii parametri (de ex. NOD, proprietar, interval de date); restul paginii este identic pentru toate rapoartele.

Completarea parametrilor

  • NOD – apăsați lupa pentru a alege NOD-ul din fereastra de selecție; X golește câmpul.
  • Proprietar – apăsați lupa pentru a alege proprietarul (apartamentul); dacă a fost ales un NOD, lista arată doar apartamentele acelui NOD.
  • Data de început / Data de sfârșit – alegeți data din calendar sau tastați-o (ZZ.LL.AAAA). Data de început nu poate fi după data de sfârșit.
  • Resetează – golește toți parametrii.

Formatul de export

  • Portable document format (.pdf) – pentru tipărire și transmitere.
  • Microsoft Excel (.xls) – pentru prelucrarea datelor.
  • eXtensible Markup Language (.xml) – pentru import în alte aplicații.
